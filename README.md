# Causal Inference PPT

因果推理相关论文的 Beamer 演示文稿，基于浙江大学 Beamer 模板。

## 项目结构

```
ppt/
├── main.tex      # 演示文稿源文件
├── zju.sty       # 浙大 Beamer 样式文件
└── figures/      # logo、背景等图片资源
```

## 编译方式

需要安装完整版 TeXLive，使用 XeLaTeX 编译：

```bash
xelatex main.tex
```

## 致谢

Beamer 模板来自 [ZJU-Beamer-Template](https://github.com/qychen2001/ZJU-Beamer-Template)。
